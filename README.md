# Perfom.agency — сайт услуг

Одностраничный сайт: таргетированная реклама, разработка сайтов, отдел продаж и чат-боты.

## Запуск

```bash
npm run dev
```

Откроется на http://localhost:3000

Сборка для публикации:

```bash
npm run build
```

## Что где правится

Весь текст, цены и цифры лежат в папке `content/` — вёрстку для этого трогать не нужно.

| Файл | Что внутри |
|---|---|
| `content/site.ts` | **Номер WhatsApp**, название, подпись, пункты меню |
| `content/services.ts` | Четыре услуги: заголовки, цены, сроки, состав работ, форматы |
| `content/cases.ts` | Показатели отдела продаж, воронка, кейсы сайтов |
| `content/reviews.ts` | Отзывы клиентов и их разбивка по направлениям |

### Поменять номер WhatsApp

`content/site.ts`, строка с `WHATSAPP`. Формат международный, без плюса и пробелов:

```ts
export const WHATSAPP = "77066620888";
```

Все кнопки на сайте подставят его сами.

### Поменять цены

`content/services.ts` — поля `price`, `priceNote`, `term` у нужной услуги.
Отдельно есть `components/sections/Configurator.tsx` → массив `ITEMS`: это вилки для калькулятора, их тоже стоит обновить, чтобы расчёт совпадал с ценами в секциях.

### Поменять цифры кейсов

`content/cases.ts`. Показатели отдела продаж пока условные — когда появятся реальные данные, замените числа `from` / `to`, разметка подстроится сама. Отраслевые результаты по таргету с сайта сняты до появления настоящих цифр.

### Добавить кейс сайта

1. Положите видео в `public/cases/` и постер-кадр рядом.
2. Допишите объект в `SITE_CASES` в `content/cases.ts`.

Видео нужно сжимать, иначе сайт будет долго грузиться. Запись экрана 2860×1352 весит ~70 МБ, для веба нужно 3–5 МБ:

```bash
ffmpeg -i input.mov -vf "scale=1440:-2,fps=30" -an -c:v libx264 -crf 28 -preset slow -pix_fmt yuv420p -movflags +faststart public/cases/case-03.mp4
```

Постер-кадр с первой секунды:

```bash
ffmpeg -ss 1 -i public/cases/case-03.mp4 -frames:v 1 -q:v 4 public/cases/case-03.jpg
```

### Добавить отзыв

1. Положите скриншот переписки в `public/reviews/`.
2. Допишите объект в `REVIEWS` в `content/reviews.ts` — категория (`sales`, `target`, `web`), размеры картинки, вынесенная цифра и короткая цитата.

Размеры указываются, чтобы карточка не прыгала, пока грузится картинка. Вкладка, у которой отзывов нет, сама покажет заглушку — специально ничего отключать не нужно.

Перед публикацией убедитесь, что на скрине не видно имён, аватарок и телефонов.

## Заяц-маскот

Четыре готовых рендера персонажа лежат в `public/mascot/`: `stand` (фронтальная стойка), `point` (присел, указывает), `back` (со спины через плечо), `arms` (руки скрещены). Фон с исходного листа снят нейросетевым вырезанием (`rembg`).

Раскладка по секциям — в `components/mascot/poses.ts`. Там же масштаб, сдвиг, зеркало и положение плиты со словом:

```ts
target: {
  src: "point",
  scale: 0.66,
  word: "ТАРГЕТ",
  slab: { side: "left", top: 30, rotate: -5 },
}
```

Все позы отрисованы сразу и лежат стопкой, видна только текущая — поэтому смена секции это перекрёстное затухание, без подгрузки картинки в момент перехода.

### Добавить новую позу

1. Вырежьте фон и положите PNG в `public/mascot/`.
2. Допишите имя файла в тип `Pose["src"]` в `poses.ts`.
3. Пропишите позу для нужной секции.

Если фон вырезать нечем:

```bash
python3 -m pip install --user "rembg[cpu]"
python3 -c "from rembg import remove; from PIL import Image; im=Image.open('in.png'); out=remove(im); out.crop(out.getbbox()).save('public/mascot/new.png')"
```

Важно: `rembg` выделяет **один** главный объект на кадр. Если на картинке несколько фигур, режьте их по одной, иначе всё кроме первой уйдёт в полупрозрачные тени.

## Верхнее меню

`components/Nav.tsx`. Пункты берутся из `NAV` в `content/site.ts` — добавили секцию туда, она сама появилась в меню.

Активный пункт определяется тем же `useActiveSection`, что и поза зайца, поэтому подсветка меню и персонаж всегда показывают одну секцию.

Клик по пункту не прыгает нативным переходом по якорю, а едет тем же плавным движением, что и колесо мыши: инстанс Lenis кладётся в `components/scrollTo.ts` при монтировании и оттуда берётся навигацией. Отступ `NAV_OFFSET` там же — он не даёт заголовку секции спрятаться под панелью.

## Акцентный цвет

Лайм `#c9f24d` — единственный акцент сайта. Токены в `app/globals.css`:

```css
--color-lime-600: #a3cc33;  /* нижняя точка градиентов */
--color-lime-400: #c9f24d;  /* основной акцент */
--color-lime-300: #dcf87e;  /* наведение */
```

Им покрашены: вторая строка каждого заголовка, кнопки WhatsApp, выбранные услуги в конструкторе, активная вкладка отзывов, полосы в дашбордах, грани карточек форматов и слово на плите у зайца. Второго акцентного цвета на сайте нет намеренно — два конкурирующих акцента размывают внимание.

Свечение курсора осталось холодным (`--color-glow-core`): это свет, а не акцент. Лаймовое затонировало бы зеленью весь экран, включая лицо зайца и скриншоты отзывов.

## Как устроены эффекты

Порядок слоёв (`app/globals.css`), снизу вверх:

```
z 0  — базовый градиент фона
z 1  — туман
z 2  — свечение от курсора
z 3  — зерно
z 5  — заяц
z 10 — весь текст и стеклянные панели
```

Свечение курсора лежит **ниже** зайца и контента — поэтому свет проходит за ними, а не поверх. Стеклянные панели полупрозрачны и через `backdrop-filter` захватывают это свечение снизу: отсюда эффект «жидкого стекла». Если добавляете новую секцию — не задавайте ей фон, иначе панели начнут захватывать его вместо свечения и эффект пропадёт.

Фон живёт на `position: fixed`, секции скроллятся поверх него — поэтому между ними нет ни одного стыка и страница читается как одно полотно.

## Стек

Next.js 16 (App Router), React 19, TypeScript, Tailwind v4, Lenis для инерционного скролла.

Собственные классы лежат в `@layer components`. Это не косметика: Tailwind держит утилиты в `@layer utilities`, а неслоёные правила по каскаду бьют любые слоёные независимо от специфичности — пока `.glass` был вне слоя, его `position: relative` перебивал утилиту `absolute` на том же элементе. Шрифты Oswald / Unbounded / JetBrains Mono / Inter подключены через `next/font` и раздаются со своего домена.
